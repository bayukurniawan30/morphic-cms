# Morphic CMS v1.1.2 — UI & Layout Refinements

This patch release focuses on improving the visual consistency and responsive behavior of the Morphic CMS dashboard. We've refined the core layout and updated several key management pages to ensure a smoother administrative experience.

---

## UI & Layout Improvements

- **Responsive Sidebar**: The sidebar now features smarter default behavior—opening automatically on large screens for quick access and remaining collapsed on mobile to maximize content space.
- **Context-Aware Header**: Optimized the header to conditionally show the "Dashboard" title only when on the main landing page, keeping the interface clean and focused.
- **Page Layout Consistency**: Refined the container spacing and maximum widths for the **API Key Abilities**, **Localization**, and **Documentation** pages to provide a more unified look across the platform.
- **Form Styling**: Improved the layout and component alignment in the API Key Abilities form for better readability and ease of use.

---

## Maintenance

- **Version Bump**: Updated the system version to `v1.1.2`.
- **General Polishing**: Minor CSS tweaks and component cleanup across various administrative views.
